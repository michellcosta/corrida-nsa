# 1ª Corrida da Paróquia de Nossa Senhora Aparecida 🏃🙏

Site oficial e sistema de inscrições da **1ª Corrida da Paróquia de Nossa Senhora Aparecida** (Galo Branco - São Gonçalo / RJ).

## 🚀 Tecnologias
- HTML5 Semântico
- CSS3 Moderno (Custom Properties, Responsividade Total)
- JavaScript Vanilla (Gestão de Inscrições, PIX dinâmico, WhatsApp e Painel Admin)
- FontAwesome Icons & Google Fonts (Outfit, Montserrat, Inter)

## 📁 Estrutura
- `index.html` - Landing Page oficial e formulário de inscrição
- `admin.html` - Painel do Organizador com gestão de inscritos e chave (toggle) de confirmação
- `css/style.css` - Estilos e Design System
- `js/app.js` - Lógica da contagem regressiva, persistência de inscritos, PIX e busca
- `assets/` - Imagens e artes do evento

## ⚡ Deploy na Vercel
Este projeto é estático (HTML/CSS/JS) e não requer build:
1. Conecte este repositório na **Vercel** (`New Project`).
2. Mantenha os campos de Framework como **Other**.
3. Clique em **Deploy**!
